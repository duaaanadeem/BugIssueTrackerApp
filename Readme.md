# Bug & Issue Tracker

University project with three parts that share **one backend and one MongoDB database**:

```
BugIssueTrackerApp/
├── Backend/   Express API
├── Mobile/    React Native / Expo client
└── Web/       Next.js client
```

Deployed API:

`https://bugissuetrackerappp.onrender.com/api`

The web app does not store its own data. Anything created on web appears in mobile after refresh, and updates from mobile appear on web after refresh.
